# Games

A collection of browser games. Each one runs in any modern web browser with nothing to install.

**Play them here:** https://rabnerjon.github.io/Games/

| Game | Description | Play |
|------|-------------|------|
| [Ashes of Hollowmere](ashes-of-hollowmere/) | A text adventure with combat and magic. Choose a Warrior, Mage or Rogue and defeat the Hollow King. | [Play](https://rabnerjon.github.io/Games/ashes-of-hollowmere/) |
| [Realmspire](realmspire/) | Chess across three stacked boards: the Skies, the Realm and the Depths. Play against a friend or a bot with three difficulty levels. | [Play](https://rabnerjon.github.io/Games/realmspire/) |

## Running locally

Open any game's `index.html` file in your web browser.
